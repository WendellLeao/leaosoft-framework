# Leaosoft Framework

A framework with many useful services and ready-to-use modular tools to make game development easier.

## Requirements

Add this dependency **first**, before installing the package. The Unity Package Manager does not resolve git-URL dependencies automatically, and skipping it will throw an exception at runtime:

- [UniTask](https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask)

## Installation

Add the package via the Unity Package Manager using a git URL:

```
https://github.com/WendellLeao/leaosoft-framework.git
```

To pin a specific version, append `#v1.0.0` (or any tag) to the URL.
